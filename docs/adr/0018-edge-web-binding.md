# Edge 扩展辅助绑定网页登录

2026-09-21，用户要求取消手动复制、粘贴网页 access token，并选择 Edge 配套扩展与一次性本机回调。接受一次安装扩展的成本，以换取日常绑定免粘贴，并避免读取浏览器配置目录或要求以远程调试模式启动日常浏览器。

这是已确认的设计记录；功能尚未完成真实 Edge 验收。实现 issue 为 [#170](https://github.com/Baker4real/kimi-switch-private/issues/170)。现行实现仍遵循 [ADR-0004](0004-web-membership-binding.md)。完整产品 spec 见 [Edge 免粘贴绑定网页登录](../specs/edge-web-binding.md)。

## 已确认的范围

- 仅 GUI 提供 Edge 辅助绑定；用户在指定账号卡上主动发起首次绑定或重新绑定。
- 用户安装配套扩展；扩展声明式注入范围限定为 `https://www.kimi.com/code/console*`，但只有页面带有本次绑定的一次性挑战片段时才读取。它不扫描其他标签页、配置或浏览器。这里的页面注入权限是 Edge 的明确站点权限，不把它描述成 `activeTab` 临时授权。
- 读取该页面的 `localStorage.access_token`，通过带一次性随机 nonce 的本机回调交给 Rust 后端。扩展不保存 token；自动读取路径不向应用主 WebView 返回 token 或 JWT 内容。
- GUI 只展示读取、校验和结果状态；不增加展示网页身份后再次确认的步骤。
- 后端继续执行目标账号身份门、独立网页凭证存储和会员读取；CLI 保留 stdin 输入，GUI 保留手动粘贴备用入口。
- 不做后台采集、跨账号自动匹配、自动续绑或静默安装扩展。
- 扩展按私有分发（issue #175）：分发包即仓库内 `edge-extension/` 源码目录（三个纯文本文件，无构建、无打包脚本，可整包审计），用户在 `edge://extensions` 以「加载解压缩的扩展」手动安装、更新（重新加载）与撤销（移除），说明见 `edge-extension/README.md`。不静默安装、不运行时下载、不要求远程调试模式，也不扫描浏览器 profile；权限面由 `src-ui/edge-extension-contract.test.ts` 静态钉住。撤销时挑战状态自动收口：挑战是本进程内存中的一次性会话（90 秒超时、关对话框即取消、一次回调即作废），扩展侧无任何持久状态可清理。

## 对现行契约的影响

实施后需要局部替代 ADR-0004 第 3 条中的“只接受用户主动复制”决定：允许用户主动发起的 Edge 扩展读取网页凭证。读取 cookie 仍不在范围内。网页凭证来源是 Local Storage，不把它称为 cookie，也不复用 Code OAuth 凭证。

网页身份仍由现有后端比对目标账号；JWT payload 解码只能证明声明身份相符，不能证明签名或凭证有效。官方接口响应负责鉴权。身份不符或无法识别时，不请求会员接口、不写凭证、不改会员元数据，也不自动改绑到其他卡。

本次保留 ADR-0004 的写序：身份门通过后先写 `web`，再请求会员数据。网络失败或官方拒绝不回滚刚写入的网页凭证；界面必须区分“凭证已保存，会员读取失败”和完整成功。抓取失败、取消、无有效绑定会话则不进入这条写入管道，旧绑定不变。

新增 loopback 通信是扩展与本机应用间的凭证交接，不是新的远端服务。扩展后台回调固定的 `http://127.0.0.1` 地址，需声明对应的 loopback host permission；页面脚本不直接跨源回调。实施前需明确项目网络白名单对这条本机通信的例外；Kimi 官方请求域名、凭证存储边界与静默会员查询限制仍按现行契约执行。

## 实施约束

软件发起绑定后不要求用户再点击扩展按钮。扩展只在带本次挑战 fragment 的控制台页面读取；fragment 只携带短时一次性 nonce 和本机回调端口，读取后立即清除。nonce 不是凭证，不能把网页 token 放进 URL、DOM、日志或命令行。

扩展后台负责向固定的 loopback listener 回调；页面脚本不直接跨源请求。回调必须校验 nonce、请求路径、请求大小和一次性消费状态；失效、重复、取消和串线请求均拒绝写入。

## 实施验收边界

一次绑定会话绑定一张目标卡，限时、可取消、只消费一次；服务只监听 loopback，按预期扩展来源接收请求。取消、过期、重复回调、跨会话回调或目标账号已删除均拒绝写入。token 只在需要的内存与现有私有凭证存储中流转。

真实 Edge 验收覆盖：正确账号免粘贴绑定；网页登录为另一账号；未登录或无 token；扩展缺失；用户取消与超时；官方会员请求失败；手动粘贴兜底。未完成真实浏览器交接前，不把单元测试通过表述为功能可用。

## 残留风险：伪造挑战 URL（reviewer F2，2026-09-21 记录）

扩展对挑战 fragment 的校验只有格式（nonce 为 48 位小写 hex、端口 1024–65535），无法区分挑战真伪。攻击者可以自行构造形如 `https://www.kimi.com/code/console#kimi-switch-bind=v1.<48位hex>.<端口>` 的链接，诱骗已在 Edge 登录 Kimi 的用户点击；此时扩展会把该页面的真实 `localStorage.access_token` POST 到链接指定的本机端口。

现有缓解：

- service worker 的回调目标是字面 `http://127.0.0.1`（契约测试钉住，不接受任意 URL），远程攻击者无法在本机之外收到这个 POST；接收方必须是受害者本机上以同一用户运行的进程。
- 真实绑定会话的 nonce 由 Rust 随机生成（24 字节随机数 → 48 位 hex），不可猜测；携带伪造 nonce 的回调不能消费任何真实挑战（nonce 不匹配即被忽略，不推进绑定状态）。
- 已能在受害者本机以同一用户运行进程的攻击者，本就可以直接读取该浏览器 profile 的 localStorage（权限相同、路径更简单）；本残留面没有扩大攻击者既有的能力面。

裁定：首版接受为已知残留面，随 #176 真机验收复核，不改回调协议。
